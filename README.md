# Simple Bank Management System

A small Java console banking system for testing.

## Features
- Login with demo users
- Create account
- Deposit
- Withdraw
- Transfer money
- Check balance
- Transaction history
- Change password
- Admin view of all accounts
- Data saved automatically to `data/accounts.dat`

## Demo logins
- Admin: `admin` / `admin123`
- User: `alice` / `1234`
- User: `bob` / `1234`
- User: `charlie` / `1234`

## Run
```bash
javac -d out src/*.java
java -cp out Main
```

Java 17+ recommended.
